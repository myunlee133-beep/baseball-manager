# DUGOUT · 야구단 운영 게임

기존 DUGOUT 운영 화면에 프로야구 10의 투구 단위 매치엔진, 경기 규칙과 능력치 계산을 연결한 브라우저 야구 게임입니다.

## 실행

Node.js 22 이상에서 `npm run dev` 후 http://127.0.0.1:4173 에 접속합니다. 실행에는 패키지 설치가 필요 없습니다.

- 선수단은 2026 KBO 10개 구단 개막 로스터 410명입니다(외국인 선수 제외). 내 팀은 KT 위즈이며 시즌은 개막 전에서 시작합니다.
- 시즌 진행: 144경기 KBO식 일정(3/28 개막), 날짜 진행(다음 날/다음 주/월말/시즌 끝), 리그 전 경기를 투구 단위 엔진으로 시뮬레이션해 순위·성적·박스스코어를 누적합니다. 선수 체력은 경기마다 소모·회복되고 능력치에 반영됩니다.
- 기록실은 올해 누적 성적이 기본이며 2025 원문 기록도 선택할 수 있습니다.
- 다음 날: 오늘 내 경기를 현재 타순·수비 위치·선발·불펜 설정으로 직접 진행합니다. 여러 날 진행은 내 경기도 자동으로 치릅니다.
- 한 구, 반 이닝, 경기 종료까지 자동 진행하고 실제 박스스코어를 확인할 수 있습니다.
- 선수마다 20–80 능력치(컨택·선구안·파워·스피드·수비, 구속·구위·제구·체력)가 저장되어 경기엔진에 그대로 쓰입니다. OVR·POT은 이 능력치에서 계산합니다. 능력치는 2025 성적과 경력으로 추정한 값입니다([변환 근거](docs/superpowers/specs/2026-09-29-kbo-2026-roster.md)).
- 구단마다 55명(국내 52 + 외국인 3)이며, 실제 로스터에 2군 뎁스 가상 선수와 가상 외국인 선수를 채웠습니다. 연봉 상위 52명은 2026 실제 연봉([조사 문서](docs/superpowers/specs/2026-09-29-kbo-2026-salaries.md)), 나머지는 능력치·연차로 추정합니다.
- 샐러리캡(국내 선수 140억, 하드캡)과 구단 예산(모기업 지원 + 순위 수입)이 있습니다. 시즌이 끝나면 오프시즌 6단계(시즌 마감 → 은퇴·방출 → 연봉 협상 → FA → 외국인 → 로스터 확정)를 거쳐 다음 시즌으로 넘어갑니다. 은퇴(나이·능력 기반 자동)와 방출·자유계약 시장(⑥에서 영입)이 동작하며, 연봉 협상(요구액 제시·연봉조정), FA(3라운드 입찰·등급별 보상), 외국인 계약(재계약·스카우팅 시장·적응 보정)이 동작합니다. 시즌 중 9월 둘째 주 월요일에는 신인 드래프트(7라운드, 잠재력 범위·플로어/실링 유형)가 열리고, 지명자는 오프시즌 로스터 확정 때 합류합니다([계약 설계](docs/superpowers/specs/2026-09-29-contract-system-design.md)).

경기는 정규 9회, 연장 최대 11회이며 이후 동점은 무승부입니다. 운영 화면(`dugout-prototype-v4`)과 진행 중 경기 저장은 분리되어 있습니다. v2·v3 저장은 편성을 유지한 채 v4로 옮겨지고(내 팀 외국인 선수는 2군에 추가), 이전 가상 선수 저장(v1)은 처음 실행할 때 지워집니다. 클라우드 동기화는 없습니다.

## 개발

`npm test`로 통합 및 원본 규칙 테스트를 실행합니다. 선수 데이터 `game/kbo-2026.js`는 `scripts/kbo-2026`에서 `npm run data:kbo`로 생성하며 직접 고치지 않습니다. `npm install` 후 `npm run build`로 엔진을 재생성하고 정적 배포 파일을 `dist`에 만듭니다. 로컬 서버에서 변경 내용을 보려면 브라우저를 새로고침하세요.

이식 범위와 저장 호환, 원본 한계, 검증 내용은 [이식 문서](docs/engine-port.md)를 참고하세요.

실제 선수 실명과 구단명을 사용합니다. 개인 개발용이며, 외부에 배포하려면 KBO·선수협 초상권·명칭 사용 허가가 필요합니다.
