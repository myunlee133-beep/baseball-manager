# DUGOUT · 야구단 운영 화면 프로토타입

PC용 KBO 특화 구단 운영 게임의 인터랙티브 UI입니다. 3D 인게임은 포함하지 않습니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 `npm run dev`를 실행한 뒤 http://127.0.0.1:4173 에 접속합니다. 패키지 설치는 필요 없습니다. 검증은 `npm test`로 실행합니다.

## 화면과 조작

- 감독 사무실: 리그 순위, 뉴스, 다음 경기 브리핑, 선수 컨디션과 부상자 메시지. 우측 상단 게임 시작은 경기 준비 점검창을 엽니다.
- 1군 라인업 / 타자: 수비 도식으로 선수를 드래그하거나 카드를 클릭해 교체. 타순 행 드래그 또는 화살표로 타순 조절. 하단에서 타자 전원 기록 정렬과 가로·세로 스크롤.
- 1군 라인업 / 투수: 선발·불펜 간 드래그로 보직 교환, 선발 내 드래그로 로테이션 조절. 불펜 역할·사용 옵션·보조 역할과 로테이션 전략 저장.
- 로스터: 1군·2군·부상자 박스 간 드래그 또는 선수 이동 선택 메뉴. 1군에서 이동한 선수는 수비·타순·투수 보직에서 해제됩니다.
- 기록실: 타자·투수·팀 기록, 내 팀/전체 리그, 기본/세부 기록, 포지션 및 이름 검색, 열별 정렬.
- 스케줄: 월별 일정, 팀 이름 클릭 시 읽기 전용 상대 1군 로스터, 완료 경기 결과 클릭 시 박스스코어.

선수 이동과 라인업·전략은 해당 브라우저의 localStorage에 저장됩니다. 별도 서버 계정이나 클라우드 동기화는 없습니다.

## 데이터와 범위

2033년 6월 14일을 기준으로 한 가상 시즌 예시입니다. 이름, 성적, 일정, 뉴스는 실제 KBO 데이터가 아닙니다. 연간 시즌 진행, 실제 경기 엔진, KBO 등록 규정 검증, 의료 판정과 복귀 제한, 라이선스 자산, 최종 선수 카드 아트는 후속 작업입니다. 부상자 이동은 UI 검토용으로 자유롭게 허용합니다. 자동 진행 전략은 저장되지만 경기 엔진에는 아직 연결되지 않습니다.

참고 자료는 화면 구조와 지표 구성을 확인하는 데 사용했으며 게임 이미지·캐릭터를 복제하지 않았습니다. 기록실은 제공된 프야9/33시즌 폴더의 타자·투수·팀 기록 사진을 참고했습니다.

## 구성

- `index.html`, `styles.css`: 공통 구조와 PC 중심 반응형 스타일
- `app.js`: 화면, 접근 가능한 입력 컨트롤, 드래그 처리, 기기 내 저장
- `model.js`: 가상 데이터, 선수 이동·라인업·로테이션 상태 변경
- `server.mjs`: 프로젝트 폴더를 제공하는 로컬 서버
- `tests/model.test.mjs`: 선수 이동 시 일관성, 중복 배치 방지, 투수 교환, 일정 검증
