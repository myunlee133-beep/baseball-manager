# DUGOUT · 야구단 운영 게임

기존 DUGOUT 운영 화면에 프로야구 10의 투구 단위 매치엔진, 경기 규칙과 능력치 계산을 연결한 브라우저 야구 게임입니다.

## 실행

Node.js 22 이상에서 `npm run dev` 후 http://127.0.0.1:4173 에 접속합니다. 실행에는 패키지 설치가 필요 없습니다.

- 홈·라인업·로스터·기록실·스케줄은 기존 DUGOUT 디자인과 데이터를 유지합니다.
- 게임 시작: 현재 타순·수비 위치·선발·불펜 설정으로 경기엔진을 구성합니다.
- 한 구, 반 이닝, 경기 종료까지 자동 진행하고 실제 박스스코어를 확인할 수 있습니다.
- 화면의 OVR과 누적 성적이 컨택·선구안·파워·스피드·수비, 구속·구위·제구·체력으로 변환되어 플레이 확률에 반영됩니다.

경기는 정규 9회, 연장 최대 11회이며 이후 동점은 무승부입니다. 운영 화면 저장과 진행 중 경기 저장은 분리되어 기존 프로토타입 데이터를 보존합니다. 클라우드 동기화는 없습니다.

## 개발

`npm test`로 통합 및 원본 규칙 테스트를 실행합니다. `npm install` 후 `npm run build`로 엔진을 재생성하고 정적 배포 파일을 `dist`에 만듭니다. 로컬 서버에서 변경 내용을 보려면 브라우저를 새로고침하세요.

이식 범위와 저장 호환, 원본 한계, 검증 내용은 [이식 문서](docs/engine-port.md)를 참고하세요.
