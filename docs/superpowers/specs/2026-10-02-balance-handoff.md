# 리그 밸런스 조정 — 인계 메모

2026-10-02 계약 시스템 세션에서 넘기는 맥락. 계약 시스템(PR 0~6, #5~#12)이 모두 머지된 뒤 처음으로 여러 시즌을 돌려 본 결과와, 이어서 정할 것들이다. 다음 세션은 **이 메모를 읽고 사용자 결정부터** 받는다(바로 숫자를 바꾸지 않는다).

관련 문서: [계약 설계](2026-09-29-contract-system-design.md) · [성장·퇴화 설계](2026-09-29-growth-decay-design.md) · [시즌 진행 설계](2026-09-29-season-progression-design.md)

## 도구

- `npm run test:balance -- [시즌 수=10] [경기 돌릴 시즌 수=0]` (`scripts/balance-smoke.mjs`)
  - 경기 없는 시즌: 월간 성장 6회 → 드래프트 자동 → 오프시즌 전체(은퇴·연봉·FA 3라운드·외국인 마감·⑥). 10시즌 수 초.
  - 경기 시즌: 리그 전 경기를 엔진으로(시즌당 약 1분). 투타 지표(ERA·OPS, 외국인/국내 분리) 출력.
  - 내 팀(KT)도 AI처럼 자동 처리(⑥에서 55명 초과분은 OVR 낮은 순 방출).
  - `NOFX=1`: 외국인 없이 시작(엔진 환경 비교용).
- 시즌마다 출력: 선수 수, 상위 276명 OVR, 평균 나이, 40세 이상, 1군 OVR, 상위 10명, 외국인 비중, 적정 연봉 합·계약 종류별 연봉, 국내 총연봉(최소·평균·최대, 캡 90% 이상 팀 수), 예산 여유, 로스터 크기, 은퇴·FA·방출·미계약 은퇴, 드래프트 코호트 성장.
- 성장만 볼 때는 기존 `npm run test:growth`(계약·경기 없이 `startNextSeason`).

## 이번 세션에서 고친 것 (브랜치 `chore/balance-check`)

1. **외국인 시장 크래시**: 외국인 중견수는 능력치 최대로도 OVR 76이 한계라 에이스급(74~80) 생성이 실패해 오프시즌 ⑤에서 게임이 멈췄다(2031년 재현). 실패하면 지명타자로 다시 생성(`league-fill.js` `foreignCandidate`). 34개 연도 풀 생성 회귀 테스트.
2. **하드캡 누수**: ⑥에서 신인이 캡 검사 없이 합류해 캡을 넘는 팀이 생겼다. AI는 ⑥을 떠날 때 `aiCapRelease`, 내 팀은 `stepBlock`("캡 초과 … 선수를 방출해 주세요")으로 막는다.
3. **AI 로스터 채우기**(사용자 승인 A): ⑥을 떠날 때 50명 미만 AI는 자유계약 시장에서 OVR 높은 국내 선수를 요구 연봉으로 영입(`release.js` `aiFillRoster`, `AI_FILL=50`). AI 원소속팀은 인원 50명 미만이면 OVR과 무관하게 FA 재계약 제시(`fa.js` `FA.keepRoster`).
4. **잠재력 낮추기**(사용자 승인 B 일부): 드래프트 잠재력 중심을 낮춤(풀 평균 잠재력 52 → 45, 60+ 17명 → 6명, `draft.js` `DRAFT.tiers`). 가상 2군 뎁스 선수의 성장 여지를 실제 선수의 절반으로(`league-fill.js` `makeDepth`).
5. 시험했다 되돌린 것: AI 구단 26세 이하 성장 배율 1.2 → 1.0(`growth.js` `judgeFit`의 `ai`). 효과 0.5포인트 안팎, 성장 테스트가 1.2를 가정해 실패. 성장 모듈은 손대지 않았다.

## 남은 문제와 사용자 결정 대기

### 1. 연봉이 캡에 붙는다 (결정 필요, 가장 급함)
- 리그 평균 국내 총연봉 10년 88억 → 130억(+45%), 2036년 9개 팀이 캡 90% 이상 → AI가 캡 초과로 계속 방출(`방출(캡 초과)`)하고 시장 영입도 못 한다.
- 원인: 능력치가 아니라 **적정 연봉 합 자체가 오른다**(81억 → 121억). 선수 연차가 쌓이면 연차 계수가 0.2 → 0.6으로 오르고, 다년 FA 계약(`kind:'fa'`, 연봉 고정)이 쌓인다(FA 연봉 합 391억 → 796억).
- 시작 시점 적정 연봉 합(81.8억)은 실제 연봉(87.9억)보다 낮아 공식 자체는 맞다.
- 선택지(계약 세션의 추천은 1):
  1. **캡과 모기업 지원금을 매년 5%씩 인상**(실제 KBO 방식). 사용자가 PR 3 때 "캡 그대로"로 정한 결정을 바꾸는 것이라 확인 필요. `FIN.cap`, `FIN.support`를 연도 함수로, `createFinance`·`beginOffseason`에서 갱신.
  2. 시장단가(`FIN.marketUnit`) 5억 → 4억: 연봉 수준 전체 −20%. 첫해에 많은 선수가 삭감되고 PR 0의 초기 연봉 보정(실제 구단 평균 ±25%)이 어긋난다.
  3. 그대로 두기.

### 2. 평균 나이가 어려지고 40세 이상이 거의 없다
- 26.4 → 24.8세. 은퇴(연 2~26명)보다 "FA·자유계약 시장에서 안 팔려" 은퇴하는 인원(연 50~80명)이 훨씬 많고, 이들은 대부분 베테랑이다.
- 1번을 정한 뒤 다시 잴 것. 후보: 미계약 은퇴 대신 일부는 1년 더 시장에 남기기, AI가 베테랑을 저가 재계약, 은퇴 확률 조정(`release.js` `RETIRE`).

### 3. 능력치 인플레이션 잔여분 (성장 모듈)
- 상위 276명 OVR이 53.8 → 57 근처에서 멈춘다(조정 전에는 계속 상승). 남은 +3은 성장 모듈 쪽: 신인·가상 선수 없이 돌려도(`test:growth`) 53.6 → 57.4까지 오른다. 기존 젊은 선수(실제 로스터의 초기 POT 공식 `OVR + 나이별 여지 + 편차`)가 POT까지 크기 때문.
- AI 성장 배율 1.2는 AI 1·2군 이동이 생길 때까지의 임시 규칙(메모리 `ai-roster-moves-deferred`). 바꾸면 `tests/growth.test.mjs`의 적정 리그 판정 테스트도 같이 고친다.
- 성장 곡선·POT 재평가 숫자는 [성장·퇴화 설계](2026-09-29-growth-decay-design.md)의 튜닝 항목.

### 4. 외국인 강세와 투고타저
- 엔진 환경 문제라 계약 범위 밖. 투고타저부터(엔진 `LEAGUE` 상수 또는 능력치 → 확률 변환) 맞춘 뒤, 외국인 등급(`FOREIGN.tiers`, 시작 배정 `FILL.foreignSlots`)을 한 단계 낮출지 본다.

## 작업 규칙
- `AGENTS.md`: 작은 PR, `model.js`·`app.js` 한 줄 포맷 유지, `dist/`는 `npm run build`로만.
- 숫자를 바꿀 때마다 `npm run test:balance`로 10시즌 전후를 비교해 PR 설명에 표로 남긴다.
- 테스트 중 일부는 시드 결과에 묶여 있다(은퇴 인원 10~45명, 드래프트 등급별 범위 등). 숫자를 바꾸면 해당 테스트의 기대 범위도 같이 확인한다.
