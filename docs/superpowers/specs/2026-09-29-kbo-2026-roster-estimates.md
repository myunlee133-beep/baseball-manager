# 2026 KBO 로스터 — 데이터 빈 곳 추정 검토

제공된 2026 로스터 원문에 없는 값을 채운 목록이다. **확정 전 검토용.**

## 기준

- 20–80 스케일, **50 = KBO 1군 주전 평균**, 표준편차 10.
- 타자: 컨택 / 선구안 / 파워 / 스피드 / 수비. 투수: 구속 / 구위 / 제구 / 체력.
- 나이 = 2026 − 출생연도 (원문 표기와 같은 방식. 예: 류현진 1987년생 → 39).
- 표기: `*` = 원문에 없어 내 기억으로 채운 값, `?` = 기억에도 없어 기본값을 넣은 값.
