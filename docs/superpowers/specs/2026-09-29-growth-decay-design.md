# 성장·퇴화 — 설계

선수 성장·퇴화 3단계 중 3단계. 인터뷰(2026-09-29)에서 확정. 전제: [1단계 리그 데이터](2026-09-29-league-data-design.md), [2단계 시즌 진행](2026-09-29-season-progression-design.md), 인계 메모 [handoff](2026-09-29-growth-decay-handoff.md).

## 목표

- 2단계의 빈 훅 `monthlyTick`·`offseasonTick`을 채워 10개 구단 410명 전원의 저장 능력치(`ratings`, 20–80)를 나이 곡선대로 성장·하락시키고 OVR을 다시 계산한다.
- POT를 해마다 변동시킨다(각성, 24–26세 재평가, 27세 이상 OVR과 일치).
- 1·2군 운영(적정 리그)이 내 팀 유망주 성장에 영향을 준다.
- 공용 받은편지함을 만들고, 성장·노화 소식을 "스카우트 리포트" 메시지로 보낸다.

## 범위 밖

- 은퇴·신인 유입: 계약 시스템 브랜치가 맡는다(사용자가 나중에 내용 공유).
- AI 구단 1·2군 이동과 AI 운영 전략 전반(오프시즌·페넌트레이스): 게임성·재미 단계.
- 경기·운영용 숨은 특성(클러치, 기복, 슬로우 스타터, 멘탈, 플래툰, 내구성, 리더십, 협상 성향, 스타성, 지도자 적성)과 스카우트 추정 POT: 게임성·재미 단계.
- "처리 필요" 메시지(선택 버튼, 처리 전 진행 불가): 실제로 쓰는 계약 단계에서 추가.
- 육성 조언 메시지(적정 리그 판정을 스카우트가 알려 주는 것): 넣지 않는다. 판정은 숨은 규칙.
- 선수 상세 화면·OVR 추이 그래프, 부상.

## 확정한 결정

| 항목 | 결정 |
|---|---|
| 성장 속도 | 나이에 따라 줄어드는 평균 속도 + 개인차. POT가 상한 |
| 하락 곡선 | 완만(KBO 베테랑형). 27–31세 0, 38세 이상 −4.5 |
| 시즌 중 변화 | 연간 변화의 30%를 달마다 5%씩 미리 반영, 70%는 오프시즌 |
| 각성 | 확률 이벤트. 1군 기회·성적과 적정 리그로 확률 보정. 27–29세도 낮은 확률 |
| 적정 리그 | 자기 수준에 맞는 군에서 뛰면 성장·각성이 빠르고, 아니면 정체. 뎁스에 막혀도 정체(×0.7) |
| AI 구단 | 적정 리그 판정 없이 항상 "적정"(AI 이동이 생길 때까지의 임시 규칙) |

| 선수별 차이 | 해마다 개인차 + 숨은 특성 넷(노력, 조숙/대기만성, 적응력, 노화 체질) + 34세 이상 급락 |
| 각성·급락 시점 | 연간 확률의 60%는 오프시즌, 40%는 시즌 중 달마다 |
| 표시 | 공용 받은편지함 + 스카우트 리포트 메시지, 중요 메시지 팝업·진행 멈춤, OVR·POT ▲▼, `history`에 OVR·POT 저장 |

계약 시스템 PR 1(저장 v4, 550명 로스터, 오프시즌 단계 분할)이 먼저 머지되고, 성장은 그 위에서 저장 v5로 구현한다(2026-09-29 결정). 맞춰 고칠 목록은 구현 계획 맨 앞에 있다.

## 무작위성

- 모든 난수는 `spread(\`${id}:${연도}:${월}:${용도}\`, salt)`류의 해시로 만든다. 같은 저장에서 다시 돌리면 같은 결과가 나오고(2단계 원칙), 난수 상태를 저장하지 않는다.
- 정규분포 개인차는 해시 두 개로 Box–Muller.
- 숨은 특성은 `spread(id, 특성별 salt)`로 선수마다 고정. 저장하지 않는다.

## 성장 규칙

### 연간 평균 변화 (OVR)

| 나이 | 평균 변화 | 곱하는 값 |
|---|---|---|
| 21세 이하 | +4.5 | 적정 리그 계수 × 노력 |
| 22–23 | +3.5 | 〃 |
| 24–25 | +2.5 | 〃 |
| 26 | +1.5 | 〃 |
| 27–31 | 0 | |
| 32–33 | −1 | 노화 체질 |
| 34–35 | −2 | 〃 |
| 36–37 | −3 | 〃 |
| 38세 이상 | −4.5 | 〃 |

- **오프시즌**(`offseasonTick`, 나이 +1 뒤라 새 나이 기준): 연간 변화 × 70% + 개인차(표준편차 2 OVR) + `pending` 정산.
- **월간**(`monthlyTick`, 현재 나이 기준): 연간 변화 × 5% × 그달 적정 리그 계수. 개인차 없음. 시즌당 6–7회.
- 성장(양수)은 POT에서 멈춘다. 하락에는 하한이 없다(능력치 20 하한만).
- 20세부터 27세까지 합은 약 +22로, 1단계 POT 공식의 성장여지(20세 +25)와 비슷하다.

### 적정 리그 계수 (26세 이하)

- **내 팀만 판정한다. AI 구단 선수는 항상 ×1.2, 각성 배율 ×2.**
- 매달 1일(`monthlyTick`)에 선수의 현재 군과 **그달 출전량**(누적 타석·아웃에서 `dev.mark`를 뺀 값)으로 판정한다. 출전 충분 기준은 한 달에 타자 50타석, 선발 13이닝(39아웃), 불펜 7이닝(21아웃). 선발/불펜 구분은 `isReliever`.

| 상황 | 성장 계수 | 각성 배율 |
|---|---|---|
| 1군 · OVR 42 이상 · 출전 충분 | ×1.2 | ×2 (성적 상위 25%면 ×3) |
| 2군 · OVR 48 미만 | ×1.2 | ×2 |
| 1군 · OVR 42 미만 (벅참) | ×0.8~1.0 (적응력) | ×1 |
| 1군 · 출전 부족 | ×0.7 | ×0.5 |
| 2군 · OVR 48 이상 (너무 쉬움, 뎁스에 막혀도 동일) | ×0.7 | ×0.5 |

- 판정 순서: 1군이면 벅참(OVR 42 미만) → 출전 부족 → 적정. `group:'injured'`는 판정하지 않는다(그달 기록 없음).
- 그달 계수를 `dev.fit.sum`에 더하고 `dev.fit.n`을 늘린다. 각성 배율도 같은 방식으로 따로 누적(`dev.fit.bsum`)한다.
- 오프시즌은 시즌 평균 계수를 쓰고 `dev.fit`을 비운다. 기록이 없으면(`n=0`) 현재 군으로 판정한다(출전량은 충분으로 본다).
- 1군 판정 기준 42는 2026 개막 1군 OVR 하위 10%, 2군 기준 48은 1군 중앙값(49) 바로 아래.

### 숨은 특성 (id 해시, 화면 비표시)

| 특성 | 값 | 효과 |
|---|---|---|
| 노력 | ×0.85–1.15 (균등) | 성장량(양수 변화)에 곱함 |
| 조숙 / 보통 / 대기만성 | 25% / 50% / 25% | 각성 확률: 조숙은 23세 이하 ×1.5·24세 이상 ×0.5, 대기만성은 23세 이하 ×0.5·24세 이상 ×1.5 |
| 적응력 | 0–1 (균등) | 1군 벅참 계수 = 0.8 + 0.2 × 적응력 |
| 노화 체질 | ×0.6–1.4 (균등) | 하락량(음수 변화)에 곱함 |

### 외국인 선수

계약 시스템이 추가하는 외국인(`foreign: true`)은 계약 설계대로 "POT = OVR, 성장 없음, 노화는 국내와 같음"이다. 성장(양수 곡선)과 각성은 없고, 하락 곡선·노화 체질·급락·개인차는 국내와 같다. POT는 매 오프시즌 OVR로 맞춘다.

### 각성

- 연간 기본 확률: 26세 이하 5%, 27–29세 2%.
- 26세 이하 확률 = 기본 × 각성 배율(적정 리그) × 조숙/대기만성. 27–29세는 기본 × 조숙/대기만성(적정 리그 무관).
- **성적 상위**: 판정 시점까지의 누적 성적이 출전 기준(시즌 200타석·선발 50이닝·불펜 25이닝을 경과 비율만큼 줄인 값)을 채운 리그 선수 가운데 타자 OPS, 투수 평균자책 상위 25%. 1군 적정 선수의 각성 배율을 ×2에서 ×3으로 올린다.
- 효과
  - 26세 이하: POT +8~+15(균등, 80 상한), 그 해 성장량(나이 평균 × 계수 × 노력)을 한 번 더 준다.
  - 27–29세: OVR +3~+5, POT는 OVR을 따라간다.
- 시점: 연간 확률의 60%를 오프시즌 한 번, 40%를 시즌 중 월간 틱마다 나눠(틱당 연간 확률 × 40% ÷ 6) 판정한다. 한 해 한 번만 각성한다(시즌 중 각성했으면 그 오프시즌은 판정 생략).
- 시즌 중 각성: POT는 즉시 올리고, 추가 성장(27–29세는 OVR +3~+5)은 절반 즉시·절반 `dev.pending`(오프시즌 정산).

### 급락

- 34세 이상, 연 5%(시점 분할은 각성과 같음, 한 해 한 번). OVR −5.
- 시즌 중 발생: 즉시 −3, `dev.pending`에 −2.

### POT

| 나이(오프시즌 새 나이) | 규칙 |
|---|---|
| 23세 이하 | 각성으로만 오른다 |
| 24–26세 | `POT += (예상 도달치 − POT) × 0.25`. 예상 도달치 = OVR + 지금 나이부터 26세까지 연간 평균 성장 합(계수 ×1.0) |
| 27세 이상 | POT = OVR |
| 공통 | 계산 뒤 `potCap(pot, ovr)`(OVR 이상, 80 이하) |

오프시즌 순서: 특성·계수 계산 → 곡선 변화 + 개인차 + `pending` → 각성·급락 → 능력치 분배·OVR 재계산 → POT 규칙.

### 능력치에 나누기

1. OVR 변화량 ΔO를 능력치 기준 변화량으로 바꾼다: `d = ΔO × OVR_BASE.sd / OVR_SPREAD` (OVR 1 ≈ 능력치 0.56).
2. 능력치별 배율 m(성장기는 ΔO > 0, 하락기는 ΔO < 0):

| 능력치 | 성장기 | 하락기 |
|---|---|---|
| 컨택 | 1.0 | 1.0 |
| 선구안 | 0.8 | 0.5 |
| 파워 | 1.2 | 1.0 |
| 스피드 | 0.8 | 1.5 |
| 수비 | 1.0 | 1.2 |
| 구속 | 1.2 | 1.5 |
| 구위 | 1.0 | 1.0 |
| 제구 | 1.0 | 0.5 |
| 체력 | 1.0 | 1.2 |

3. 정규화: 선수의 OVR 가중치 w(`OVR_WEIGHTS`, 포지션·보직별)로 `k = Σ w·m`을 구하고 능력치 변화 = `d × m / k`. 가중치에 없는 능력치(지명타자의 스피드·수비)는 `d × m`.
4. 소수 부분은 해시 확률 반올림(0.3이면 30% 확률로 1 더). 결과를 20–80으로 자른다.
5. `p.ovr = ovr(p)`, `p.pot = potCap(p.pot, p.ovr)`.

`OVR_WEIGHTS`와 `weightsFor` 로직은 `player-ratings.js`에서 가져온다(`weightsFor`를 export).

## 받은편지함 (`game/inbox.js`)

```js
pushMessage(state, { from, subject, body, importance = 'normal', date = state.season.date })
// state.inbox 맨 앞에 { id, date, from, subject, body, importance, read: false, shown: false }
// 200개를 넘으면 오래된 것부터 버린다
pendingPopup(state)    // importance 'high' 이고 shown false 인 메시지들
markShown / markRead / markAllRead / removeMessage
```

- `body`는 `[{ p: '문단' } | { table: { head: [...], rows: [[...]] } }]` 구조. 화면에서 `esc`로 이스케이프해 그린다.
- 계약 브랜치 등 다른 시스템도 `pushMessage`로 보낸다. "처리 필요" 필드는 계약 단계에서 추가한다.

### 3단계가 보내는 메시지 (보낸 사람: 스카우트 팀장)

| 메시지 | 시점 | 중요도 | 내용 |
|---|---|---|---|
| 월간 스카우트 리포트 | 월간 틱, 내 팀에 능력치 변화가 있을 때만 | 일반 | 선수별 능력치 ±, OVR 이전 → 이후 |
| 긴급 스카우트 리포트 | 내 팀 선수 각성·급락 발생 시 | 중요 | 각성: "○○○, 타격에 눈을 떴습니다" + POT 이전 → 이후. 급락: "○○○의 기량이 눈에 띄게 떨어졌습니다" + OVR |
| 오프시즌 스카우트 리포트 | 오프시즌 틱 | 중요 | 내 팀 전원 OVR·POT 이전 → 이후(변화 큰 순), 리그 전체 각성·급락 명단 |

다른 팀 선수의 각성·급락은 `season.news`에 한 줄로 올린다. 오프시즌 틱에서 넣은 소식은 새 시즌 생성 때 지워지므로 오프시즌 리포트 명단에만 남는다.

## 진행 흐름 연결

- `league-season.js`: `hooks = { monthlyTick: monthlyGrowth, offseasonTick: offseasonGrowth }`. 호출 위치·순서는 2단계 그대로(`finishDay`에서 새 달 1일, `startNextSeason`에서 성적 이동·나이 +1 뒤).
- `season-runner.js`: `finishDay`·저장 뒤 `pendingPopup(state).length`가 있으면 `{ done, total, stopped: 'message' }`로 멈춘다.
- `app.js`: 진행이 끝나거나 멈춘 뒤, [다음 날] 하루가 끝난 뒤, [다음 시즌으로] 뒤에 `pendingPopup`이 있으면 팝업을 띄우고 `shown` 처리한다.

## 화면 (`app.js`)

- 주 메뉴: 감독 사무실 · 1군 라인업 · 로스터 · 기록실 · 스케줄 · **메시지**. 안 읽은 메시지 수 배지.
- 메시지 화면(OOTP "뉴스 및 메일" 참고): 도구줄(보낸 사람 필터, 제목 검색, [모두 읽음], [삭제]), 왼쪽 목록(중요 "!", 안 읽음 굵게, 제목, 날짜), 오른쪽 본문(제목·보낸 사람·날짜·문단·표). 열면 읽음. 좁은 화면에서는 목록 → 본문 한 칸 전환.
- 팝업: 기존 `showModal`. 중요 메시지 하나면 본문, 여러 개면 제목 목록. 버튼 [확인] [메시지함으로].
- 홈 "메시지" 상자: 부상자 안내 자리를 최근 메시지 3개로 교체, 누르면 메시지 화면.
- ▲▼: 로스터·라인업·후보 선택 표의 OVR·POT 옆에 `history[지난 연도]` 대비 변화(`62 ▲3`, `58 ▼2`). 기록이 없으면 표시 안 함.

## 오류 처리

- 능력치·OVR·POT가 범위를 벗어날 수 없게 분배 마지막에 자른다.
- 메시지 본문은 문자열 HTML을 저장하지 않고 구조로 저장해 이스케이프한다.
- 저장 용량 초과는 2단계 처리(진행 멈춤·모달)를 그대로 따른다. `inbox`는 200개 제한으로 약 수십 KB 이내.

### 튜닝 스모크 `scripts/growth-smoke.mjs` (테스트 아님)

경기 없이 월간 6회 + 오프시즌 틱을 10시즌 반복하며 연도별 출력: 상위 276명 평균 OVR과 하위 10%, 나이대별 평균 OVR, 각성·급락 건수, POT 80 인원, 김도영·최민석·신재인·양의지·최형우 궤적. 인터뷰 때 평균값 추정(상위 276명 평균 약 50을 4년 유지)과 크게 다르면 숫자를 조정하고 이 문서에 기록한다.

## 인터뷰 때 참고한 추정 (평균값, 개인차·이벤트 제외)

- 최민석(20세 선발, 52/80): 1군 선발로 쓰면 27세 무렵 약 80. 2군에 계속 두면 27세 약 70, POT 약 72.
- 신재인(19세 2군, 31/62): 계속 2군이면 27세 약 53, POT 약 55.
- 양의지(39세 포수, 66): 1년 뒤 61.5, 2년 뒤 57, 3년 뒤 52.5(체질 보통).
- 은퇴 없이 6시즌: 상위 276명 평균 OVR 50.4 → 2030년 50.1 → 2032년 48.8, 40세 이상 10 → 74명.

## 알려진 한계

- 은퇴·신인이 없어 평균 나이가 매년 +1씩 오른다. 계약 브랜치의 은퇴·드래프트가 들어오면 해소된다.
- AI 구단은 적정 리그 판정을 받지 않는다(항상 적정). AI 1·2군 이동이 생기면 내 팀과 같은 판정으로 바꾼다.
- 체력이 45를 넘나들면 선발/불펜 가중치가 바뀌어 OVR이 3–4 튈 수 있다(1단계 정의 그대로).
- 2군 경기는 시뮬레이션하지 않아 2군 선수는 성적 보정을 받을 수 없다.
- 트레이드가 없어 뎁스에 막힌 유망주를 풀 수단이 콜업·벤치 기용뿐이다.
