# 계약 시스템 — 설계

KBO 선수 계약 구조(신인 드래프트, 연봉 협상, FA, 외국인 선수, 은퇴·방출)를 게임에 넣는다. 인터뷰(2026-09-29)에서 확정. 전제: [1단계 리그 데이터](2026-09-29-league-data-design.md) 머지 완료, [2단계 시즌 진행](2026-09-29-season-progression-design.md)(`feat/season-progression`) 머지 후 착수.

## 목표와 핵심 재미

- 재정 압박, 육성, KBO 제도 재현의 조합. 중심은 **팀 단위 빌딩**이다. 개별 선수 협상의 디테일보다 "이번 오프시즌에 팀 전력과 재정을 어떻게 배분할까"가 판단의 단위다.
- 매 시즌이 끝나면 단계형 오프시즌을 거쳐 다음 시즌 팀을 꾸린다. 9월에는 신인 드래프트가 열린다.
- AI 9개 구단도 모든 단계에 참여한다. 단, 이번 범위의 AI는 **자리 채우기용 최소 규칙**만 쓰고 전략은 후속 "게임성·재미" 단계에서 교체한다.

## 범위 밖 (후속 작업)

| 항목 | 비고 |
|---|---|
| WAR | 선수 가치는 OVR + 올해 성적으로 시작. WAR이 생기면 가치 공식의 성적 항을 교체 |
| 트레이드 | 보류. 설계 시 AI 가치 평가에 팀 약점 포지션 반영 예정 |
| 은퇴 만류 | 노화 곡선 도입 이후. 만류 1년·선수당 2회·주전급 한정·확률 성공 초안 |
| AI 운영 전략 | 오프시즌·페넌트레이스 AI 전략 전반. 게임성·재미 단계 |
| 군 입대, 육성선수, 2차 드래프트, 포스팅, 비FA 다년계약 | 후속 |
| 사기(케미스트리) | 연봉 삭감의 불이익은 이번 범위에서 연봉조정 리스크뿐 |

## 전체 흐름

```
정규시즌 ── 9월 둘째 주 월요일: 신인 드래프트 (지명권만 확보)
시즌 종료 → [오프시즌 시작]
 → ① 시즌 마감      자동: 성적 보관, 순위 수입 정산, 시즌 요약
 → ② 은퇴·방출      내 결정 → AI 결정
 → [나이 +1, 노화]  리그 전원 + 자유계약 시장 선수
 → ③ 연봉 협상      노화 결과 요약을 먼저 보여줌
 → ④ FA            3라운드 입찰 + 보상
 → ⑤ 외국인 계약
 → ⑥ 로스터 확정    지명자 합류, 인원 검사, AI teamSetup
 → [새 시즌 시작]
```

- 은퇴·방출은 노화 **전**, 올해 보여준 능력으로 결정한다(미래 하락을 미리 알 수 없게). 돈이 오가는 ③~⑤는 노화 **후** 능력으로 계산한다.
- 은퇴 확률도 노화 전 나이·능력 기준이다. 은퇴가 너무 적으면 확률 상수로 조정한다.

## 확정 결정

### 로스터

- 구단당 **55명 상한**(외국인 포함). 신규 게임 시작 시 국내 선수를 가상 선수로 52명까지 채우고 외국인 3명을 배정해 모든 팀을 55명으로 만든다.
- 채우는 가상 선수: 전원 2군, OVR 30~42, 나이 19~27, 팀별 부족 포지션 우선. `generated: true`는 내부 데이터로만 두고 **화면에 표시하지 않는다**.
- 방출된 선수는 자유계약 시장으로 가고, 오프시즌 동안 아무도 계약하지 않으면 은퇴한다.

### 재정

금액 단위는 만 원. 모든 수치는 `game/contract/finance.js` 상수 한 곳에 둔다.

- **하드캡**: 국내 선수 전원 연봉 합계 ≤ **140억**(실제 2026 캡 약 137억(상위 40명) + 15명 × 최저연봉). 외국인 제외. 계약을 맺으면 캡을 넘는 경우 **계약 자체가 불가**. 시작부터 넘는 팀은 방출만 가능하고 새 계약은 막힌다.
- **구단 예산**(1년 단위, 이월 없음) = 모기업 지원금 + 순위 수입(전년도 최종 순위). 지출 = 국내 연봉 합계 + 외국인 연봉(원화).
  - 모기업 지원금: 상 170억(삼성, LG, SSG, KIA) / 중 150억(두산, 롯데, 한화, NC, KT) / 하 120억(키움).
  - 순위 수입: 1위 +20억 … 10위 +2억(2억 간격). 첫 시즌은 전 팀 +10억.
- 최저연봉 3,000만. 외국인 연봉은 달러, 고정 환율 1달러 = 1,400원.

### 선수 가치와 연봉 요구액

```
가치 = OVR 가치 × 0.6 + 성적 가치 × 0.4 × 출전 비중
  OVR 가치   = max(0, (OVR − 45) / 5)                       // OVR 50 → 1, 60 → 3, 70 → 5
  성적 가치  = 타자 OPS, 투수 평균자책·이닝의 리그 평균 대비 점수를 같은 스케일로 환산
  출전 비중  = PA/(PA+200) 또는 IP/(IP+60)                  // 출전이 적으면 OVR 쪽으로 수렴
적정 연봉 = max(3,000만, 가치 × 5억 × 연차 계수)
  연차 계수: 1~3년차 0.2 / 4~6년차 0.4 / 7년차 이상 0.6
요구액(인상) = 전년 + (적정 − 전년) × 0.6
요구액(삭감) = 전년 − (전년 − 적정) × 0.5,  삭감 상한: 1억 이상 40% / 1억 미만 30%
```

- 초기 연봉: 연봉 상위 약 50명은 실제값(PR 0), 나머지는 성적 없이 OVR 가치만으로 적정 연봉을 쓴다(OVR이 이미 2025 성적에서 나와 이중 반영 방지). 가상 선수 3,000만~4,000만.
- 보정: 팀별 국내 총연봉이 KBO 공식 2026 구단 평균 연봉 × 52명의 ±25% 이내가 되도록 시장단가(5억)를 조정한다(실제 리그 평균 팀 총연봉은 약 93억, 캡의 66%).

### 연봉 협상 (③)

- 시스템이 선수별 요구액을 제시한다. [전원 요구액 수용] 한 번 또는 선수별 금액 조정.
- 요구액보다 낮게 제시하면 확률적으로 수락한다: 95% 이상 85% / 90% 60% / 85% 35% / 80% 15% / 80% 미만 0%.
- 거절하면 연봉조정: 구단안 약 70%, 선수안 약 30%로 채택.
- FA 자격을 얻은 선수는 협상 대상에서 빠진다. 미처리 선수는 단계를 넘길 때 요구액으로 자동 수용.
- 확정 규칙(PR 3): 가치 = OVR 가치 × (1 − 0.4w) + 성적 가치 × 0.4w(설계 초안의 `×0.6 + ×0.4w`는 출전이 적으면 가치가 줄어 가중 평균으로 변경). 성적 가치는 직전 시즌 OPS·평균자책을 리그 기준 선수(100타석·30이닝+) 평균·표준편차로 `50 + 8z` OVR 척도로 환산. 대상은 계약 마지막 해 국내 선수(FA 자격자 제외), 다년 계약은 1년 차감. 선수당 제시 1회, 판정은 `연도:id` 해시. FA 자격자는 PR 4 전까지 요구액으로 자동 재계약·재자격 +4. AI는 전원 수용 후 캡 초과분을 OVR 낮은 순으로 방출. 캡 초과(확정 예상 총연봉 기준)면 ③에서 진행 불가, ③에서도 방출 가능. 삭감 하한은 최저연봉 아래로 내려가지 않는다.

### FA (④)

- **자격**: 연차 기준. 고졸 8시즌, 대졸 7시즌, 이후 재자격 4시즌. `faYear`가 원문에 있으면 우선, 없으면 PR 0 조사값, 그것도 없으면 `나이 − 입단 나이(고졸 19, 대졸 23) − 군 복무 약 1.5년`으로 추정.
- **등급 A/B/C**와 보상: 원소속팀이 보호선수 외 1명 + 연봉 일정 배수, 또는 보상금. 등급 경계와 보호 인원은 55명 로스터에 맞춰 PR 4에서 정한다.
- **계약**: 기간 + 연 평균 연봉. 계약금·옵션은 총액에 포함.
- **3라운드 입찰**: 라운드마다 각 구단이 조건을 제시, 선수는 라운드 끝에 최고 제안을 수락하거나 다음 라운드까지 대기.
  ```
  제안 점수 = 총액 × 기간 선호 보정 × (1 + 원소속팀 가산 약 10% + 우승 경쟁력 가산 0~10%)
  ```
  기간 선호: 30대는 긴 계약, 20대는 짧은 계약 선호. 우승 경쟁력은 전년 순위 기반.
- 보상선수·보상금은 계약 성사 즉시 처리.

### 외국인 (⑤)

- 팀당 3명, 같은 포지션(투수/타자) 최대 2명. 신규 선수 첫해 총액 상한 100만 달러, 재계약은 상한 없음. 캡 제외, 예산 차감.
- **시작 배정**: 신규 게임 시 팀마다 투수 2 + 타자 1(가상 선수). 공정성을 위해 전 팀 같은 등급 구성: 1선발 OVR 74~78, 2선발 68~73, 타자 62~68(능력치 범위 안에서 뽑되 등급에 맞을 때까지 다시 뽑는다). 시드 고정. 적응 보정 없음. 연봉 1선발 약 130만, 2선발 약 100만, 타자 약 110만 달러(±15%).
- **능력치 모양**: 투수 구속 60~75 · 구위 55~70 · 제구 40~62 · 체력 55~70(구속과 제구 약한 반비례). 타자 파워 60~75 · 컨택 45~62 · 선구안 40~60 · 스피드 30~50 · 수비 35~50, 포지션 1B/LF/RF/DH 80%. 나이 26~33, `pot = ovr`(성장 없음), 노화는 국내와 같음.
- 이 범위는 현재 OVR 공식(`OVR_BASE` 평균 47.1, 표준편차 4.45 → OVR 8)에서 투수 평균 OVR 약 73, 타자 약 63(지명타자 약 70)이 된다. 능력치 범위를 유지하고 **OVR 등급을 이 범위에 맞춘다**(2026-09-29 결정). 외국인 투수 대부분이 국내 상위 5명(OVR 72 이상) 수준이며, 시즌 스모크로 리그 투타 균형을 확인한다.
- **시장 풀**: 매년 18명(투수 12, 타자 6). 에이스급 2(OVR 74~80) / 1선발·중심타자급 5(68~74) / 평균 7(62~68) / 위험 4(55~62). 해마다 풀 강도 변동. (시작 배정 등급을 올린 만큼 인터뷰 때 값(65~72 / 60~65 / 55~60 / 48~55)에서 올렸다. PR 5에서 원래 능력치 범위로 실제 분포를 보고 확정한다.)
- **적응 보정**: 시장에서는 능력치가 스카우팅 값 ±5 범위로 보인다. 계약 순간 선수 공통 보정 −8~+4(음수 쪽으로 치우침)이 정해져 실제 능력치가 확정된다. 재계약 선수는 실제 능력치가 보인다.
- **별도 능력치 상한 없음**: 능력치 범위(개별 최대 75) + 적응 최대 +4 + 무성장 + 20–80 스케일로 충분. OVR은 공식의 상한 80을 넘지 않는다.
- AI와 경쟁 입찰(FA 입찰 로직 재사용).

### 신인 드래프트 (9월)

- 9월 둘째 주 월요일(휴식일)에 열린다. 여러 날 진행 중이어도 이날 멈춘다. 지명 순서는 전년도 최종 순위 역순, 2026년은 드래프트 당일 순위 역순.
- 7라운드(매년 70명 지명). 지명자는 권리만 확보하고 ⑥에서 로스터에 합류한다.
- **풀**: 약 100명, 지명되지 못한 선수는 사라진다. 기본 분포: 즉시전력 1~2(현재 45~52, 잠재 60~75) / 상위 유망주 8~10(30~42, 58~72) / 중위 25~30(28~40, 48~60) / 뎁스·도박 나머지(25~38, 35~55). **해마다 풀 강도 변동**(풍년·흉년), 오프시즌 초반 뉴스로 예고.
- **저점·고점**: 유망주마다 잠재력 저점과 고점을 두고 실제 잠재력은 그 사이에서 가운데가 두꺼운 분포로 뽑는다. 화면에는 범위만 보인다.
  - 플로어픽(예: 52~58, 현재 42), 밸런스(48~64, 현재 35), 실링픽(38~75, 현재 28). 유형 간 기댓값은 비슷하게 맞춘다.
- **고졸·대졸** 약 6:4. 고졸 18세, 현재 낮음, 실링 성향, FA까지 8시즌. 대졸 22세, 현재 높음, 플로어 성향, 7시즌.
- 성장 속도는 성장·노화 작업의 영역. 드래프트는 현재 능력, 저점·고점, 실제 잠재력만 만든다.

### 은퇴·방출 (②)

- 자동 은퇴: 나이와 능력으로 확률 계산, 오프시즌 뉴스로 발표.
- 내 팀은 방출할 선수를 고른다. 방출자는 자유계약 시장으로 가고, 미계약이면 오프시즌 끝에 은퇴.
- 은퇴한 선수는 상태에서 지우고 뉴스 기록에만 이름을 남긴다.
- 확정 수치(PR 2): 기본 확률 33세 2% · 34세 5% · 35세 10% · 36세 18% · 37세 28% · 38세 40% · 39세 55% · 40~41세 70% · 42세 이상 90%, OVR 60 이상 ×0.5 · 40 이하 ×1.5. 2026 개막 리그 기준 연 약 24명. 판정은 `연도:선수 id` 해시로 재현 가능.
- 자유계약 시장은 `state.offseason.freeAgents`(오프시즌 동안만). 요구 연봉 = 적정 연봉, 보류 1년. 영입은 ⑥에서만. 방출 선수의 잔여 연봉은 사라진다(단순화). 시장 선수는 노화 때 나이만 +1(성장·노화 훅 미적용).

### AI 최소 규칙 (후속 단계에서 교체)

| 단계 | 규칙 |
|---|---|
| 드래프트 | 남은 후보 중 `현재 능력 + 잠재력 중앙값` 최대 |
| 은퇴·방출 | 55명 초과분을 OVR 낮은 순으로 방출. 자유계약 시장에서 영입하지 않음 |
| 연봉 | 요구액 전원 수용. 캡 초과 시 OVR 낮은 순 방출 |
| FA | 원소속팀이면 요구액으로 재계약 시도. 캡·예산 여유가 있으면 OVR 상위 FA 입찰 |

### 저장

- 저장 v3(와 v2) → v4. 마이그레이션: 계약 필드 채우기, 55명 채우기, 외국인 배정. AI 팀 외국인은 바로 1군(선발 SP·주전 보직, 같은 유형 최저 OVR 선수를 2군으로)이다. AI 편성은 경기마다 `teamSetup`으로 다시 계산되므로 사용자 편성과 충돌하지 않는다. 내 팀 외국인은 2군에 두고 사용자가 직접 올린다(기존 편성 유지). ⑥에서 따로 재편성하지 않는다.
- 새 게임(`initialState`)에서는 내 팀도 외국인을 1군에 넣은 뒤 `teamSetup`을 돌린다. 외국인 선발 1명마다 원래 SP 보직 중 최저 OVR 선수를 RP로 바꿔 로테이션 5명을 유지한다.
- 드래프트 풀과 외국인 풀은 해당 단계가 끝나면 지운다. 선수 550명 약 350KB + 박스스코어 약 1.6MB로 localStorage 한도(약 5MB) 안.

## 알려진 한계

- 초기 연봉은 상위 약 50명만 실제값이고 나머지는 추정이다.
- 연차와 FA 시점은 주요 선수 외에는 나이 추정이라 실제와 몇 년 어긋날 수 있다.
- 첫 시즌 순위 수입과 첫 드래프트 순서는 전년도 데이터가 없어 임시 규칙을 쓴다.
- AI는 최소 규칙만 따르므로 전략적으로 움직이지 않는다.
- 포스트시즌이 없어 성적 수입은 정규시즌 순위로만 계산한다.
