# 프로야구 10 → DUGOUT

원본 `프로야구 10/lib/game`의 12개 TypeScript 모듈을 `vendor/pro-baseball`에 보존했다. 브라우저 ESM은 `game`에 생성한다. 엔진 상수·확률·보정·규칙은 그대로 유지한다.

## 이식 범위

- 투구: 카운트별 스윙, 인지 위치, 파울, 삼진, 볼넷, 사구, 고의사구.
- 타구·수비: 타구 속도/각도/방향, 수비 자격·숙련도, 실책, 병살, 인필드 플라이, 희생플라이, 번트, 도루.
- 경기: 9회 정규, 최대 11회 연장과 무승부, 끝내기, 재출장 제한, 대타·대주자·대수비·투수 교체, 책임 투수/자책점, 승패·세이브·홀드.
- 능력치: 20–80(평균 50). 타자 5개, 투수 4개, 히든 능력과 타구 성향, 피로도. 화면 종합값은 표시 능력치 평균이며 별도 엔진 입력이 아니다.
- DUGOUT의 홈·라인업·로스터·기록실·스케줄 화면 및 선수 데이터는 변경하지 않는다.
- 게임 시작 때 DUGOUT의 현재 타순·수비 위치·선발·불펜 보직을 원본 경기엔진의 팀 상태로 변환한다. 한 구, 반 이닝, 경기 종료까지 진행할 수 있으며 실제 박스스코어를 표시한다.

## 저장

기존 운영 화면은 계속 `dugout-prototype-v1`을 사용한다. 진행 중 경기만 별도 키 `dugout-active-game-v1`에 저장한다. 카운트·주자·난수 상태가 포함되므로 새로고침 뒤에도 같은 결과로 이어진다. 경기 결과는 운영 화면의 가상 시즌 기록을 덮어쓰지 않는다.

## 원본 범위와 한계

이번 범위는 매치엔진과 경기 규칙, 능력치 연결이다. 원본의 미니 시즌 화면·선수 명단·운영 UI는 가져오지 않았다. 3D 경기 연출도 추가하지 않았다.

DUGOUT의 화면 OVR·시즌 성적을 20–80 엔진 능력치로 변환한다. 타자의 타율·삼진율은 컨택, 볼넷율은 선구안, 홈런율은 파워, 도루와 OVR은 스피드·수비에 반영된다. 투수의 K/9은 구위, BB/9은 제구, OVR은 구속과 보조값, 선발/불펜 보직은 체력에 반영된다. 실제 경기는 `game/engine.js`를 사용한다.

## 검증 및 빌드

`npm test`: 기존 22개 + DUGOUT 변환/경기 통합 + 원본 smoke/ratings/pitch/play-script/rules 테스트. 원본 테스트는 36,000타석 비교, 끝내기·11회 무승부·고의사구 등을 검증한다.

`npm run build:engine`은 원본 TypeScript와 테스트에서 ESM을 생성한다. JS도 포함하므로 실행과 테스트에는 패키지 설치가 필요 없다. 빌드는 `npm install` 후 `npm run build`. 생성된 정적 사이트는 `dist`에 저장한다.
